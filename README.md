# AI-VISUALIZATION
Interactive, client-side Executive Sales &amp; Operations Dashboard built with HTML, Chart.js, and SheetJS. Supports dynamic filtering and custom Excel/CSV dataset uploads.

Executive Sales & Performance Dashboard is a responsive, single-file web application designed for real-time analytics, KPI tracking, and operational insights. It features interactive slicers, dynamic charts powered by Chart.js, and support for custom Excel/CSV file parsing directly in the browser via SheetJS.
  
Key Features :
Dynamic Slicers & Filters: Filter data by region, product, target status, and delivery timeframe in real time.  
Interactive Visualizations: Includes combo, doughnut, bar, horizontal bar, and scatter plot charts driven by Chart.js.  
Custom Dataset Upload: Parse and display custom .xlsx or .csv files locally using SheetJS without backend setup.  
Responsive Dark Theme UI: Built with Plus Jakarta Sans typography and Lucide icons for a modern executive interface.
